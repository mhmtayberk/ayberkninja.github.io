{% raw %}# About Me

> About Mehmet Ayberk Annadınç, an application security engineer and AWS Community Builder focused on web, mobile, API, cloud and AI security.

- Author: [Mehmet Ayberk](https://ayberk.ninja/about.html)
- Language: English
- Canonical: [https://ayberk.ninja/about.html](https://ayberk.ninja/about.html)

I'm an Application Security Engineer at <a href="https://www.intertech.com.tr/" target="_blank" rel="noopener noreferrer">Intertech</a>, where I work on manual web, mobile and API security testing, secure development practices, source code analysis, and the use of SAST and DAST tools.

Before joining Intertech, I worked as a penetration tester with a focus on web applications, APIs, internal networks, Wi-Fi security and cyber threat intelligence. These days, my research interests also include AWS and AI security. I share the things I learn and test on this blog.

I'm an <a href="https://aws.amazon.com/developer/community/community-builders/" target="_blank" rel="noopener noreferrer">AWS Community Builder</a> in the Security & Identity category. I occasionally speak at and teach community events in Turkey.
